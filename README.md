# Skyrim DB-W

An offline desktop app for looking up Skyrim SE/AE data: NPCs, locations and quests, including
Dawnguard and Dragonborn (Solstheim). Built with Tauri 2, React and TypeScript. Windows only.

> Unofficial fan project. Not affiliated with, endorsed by or sponsored by Bethesda Softworks or ZeniMax Media.

## Features

The app opens on Locations; switch sections from the sidebar.

- **NPCs**: uniquely named characters with a short "who and where" description.
  Filters: Marriable, Follower, Unique, DLC and area. Followers also show how to recruit them,
  primary skills and max level.
- **Locations**: exteriors (map markers, copy `player.moveto`) and interiors (cells, copy `coc`),
  each with a short description of where it is. Filters: DLC, exterior/interior and category.
- **Quests**: giver, locations, reward, quest ID, quick and detailed walkthrough, and stage numbers
  with a one-click `setstage` command.

Entries link to each other: an NPC jumps to its location, a quest jumps to its locations and giver.
Everything works offline once the data is built.

## Building from source

### Prerequisites (once)

- [Node.js](https://nodejs.org) LTS
- [Rust](https://rustup.rs) (rustup, MSVC toolchain)
- Visual Studio Build Tools with "Desktop development with C++" and the Windows SDK
  (WebView2 ships with Windows 11)
- Python 3, only to build the data
- Git, only to publish

### Run

```bash
npm install
npm run tauri dev                 # development mode
npm run tauri build               # installer in src-tauri/target/release/bundle/
```

The project ships with a few sample entries so the interface works before you build the data.

### Building the data

The scripts need internet access; the app itself works fully offline. Downloaded pages are cached in
`scripts/cache/`, so re-running is fast. Add `--refresh` to download everything again.

```bash
python scripts/fetch_markers.py     # exterior map markers  -> src/data/markers.json
python scripts/fetch_followers.py   # follower details      -> src/data/followers.json
python scripts/build_locations.py   # -> src/data/locations.json  (--no-interiors to skip interiors)
python scripts/build_npcs.py        # -> src/data/npcs.json
python scripts/build_quests.py      # -> src/data/quests.json + src/data/quest-details.json
```

Run `fetch_markers.py` and `fetch_followers.py` first, since the build scripts use their output.
`build_quests.py` downloads several hundred pages the first time and can be re-run if it stops.
If a script finds too little data, it leaves the existing file untouched.

### Project structure

```
src/
  App.tsx                 sidebar (sections + filters), section switching
  nav.ts                  navigation context (jump between sections with a search)
  categories.ts           the three sections
  types.ts                data types
  components/             SearchBox, Filters, Toast
  hooks/useIncremental.ts renders long lists in chunks
  views/                  NpcsView, LocationsView, QuestsView
  data/                   JSON generated by the scripts
scripts/
  uesp_common.py          download, cache and HTML parsing helpers
  fetch_*.py, build_*.py  data builders
src-tauri/                Rust shell (Tauri)
```
